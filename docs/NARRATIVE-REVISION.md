# 正文修订 scene-pass-2

叙事从许砚的夜班现场开始。原聊天仍是素材来源，发送人不进入角色表；正文不再由群友向玩家转述。

## 节奏与观察范围

第一夜的工牌、坏水龙头、没记全的工时，第二夜的面试预演、麦茶和没说透的邀请，第三夜的食券机、末班车、桥下纸巾，到回国三天里没打开的工作消息，形成事件之间的生活过程。主角有疲惫、动心、怕麻烦和想先安静一晚的想法；这些判断未必可靠，后果在之后的消息与行动里出现。

控制行为按干涉物品与排班、截断同事交流、追问回复顺序、偷拍视频、替主角回答、墙边暴力、凌晨堵门、关系与申请材料施压升级。保留原事的墙边冲突、敲窗、猫眼、追逐和枕上信封，没有把凛写成一次谈话后迅速悔改的人。

对其他人的心理，优先写主角看见的动作、听见的话和自己的猜测。通话和视频始终保留距离；死亡结局停在主角最后能感知的画面与声音，不切到离体镜头。

囚困分支是改编新增的假设性噩梦路线。扩写回收门锁钥匙、两部手机、三张合照、三个闹钟与“只说五分钟”，让许砚实际尝试开门、呼救和取回钥匙；邻居没有靠近时不替他们判断动机。最终由钥匙、失效通讯和不断重置的离开条件共同构成囚困，而不是让主角仅仅因为一次翻身声便放弃行动。

未接来电分支的雨夜事故同样为改编新增。睡前预演约定给 04:17 的来电提供当夜原因；司机下车报警、急救被呼叫，凛从否认转为慌乱回答位置，但不因此免除追逐责任。全文保持非血腥的第一人称感知，不增加事故后的离体说明或巧合救援。

## 证据与现实后果修订

照片、截图、录音和纸面材料不再直接代替后果。跟踪照片只说明曾有拍摄视角，伤痕照只记录伤，裁剪图依靠被删掉的人名与上下文改变印象；后续结果必须由接收者的判断和行动完成。共通篇提前放入完整工作群原文，晚晴线可以直接核对“我陪你和七濑去家庭餐厅”如何被裁成“我陪你”。报警留下事件编号与联系人，校内说明与报警补充材料分开交接。

学校给的是这所虚构学校的一次个别安排：允许补交材料并改为书面复审，不重新安排面试。补交、复审与录取结果不再混用，也不把私人照片当成自动取消资格的依据。住房、仓库工作、国际交通、工资和既有关系按各路线实际选择收束。
