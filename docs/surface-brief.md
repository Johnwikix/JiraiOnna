# 游戏阅读界面 · 1.1

Mode: Experience，阅读时让场景和对白占据视野；暂停菜单、设置、存档、衣装浏览与场景回忆为 Operate。用户已认可 v3 日系二维角色方向，并授权多代理制作服装、CG 与游戏接入。本轮扩展原有界面，不重做设计方向。

## Direction contract

THESIS: 一部从许砚赶赴另一份夜班的现场切入、在凌晨敲窗与追逐中失控的日系视觉小说。玩家以第一人称按时间顺序经历冲突，界面让位于场景，选项像临场决定，结局有代价。

OWN-WORLD: 炭黑 #14151b、深梅紫 #222029、纸白 #f0edf0 与淡樱粉 #dda0b7。标题使用本地 Story Serif，正文与控件用中文黑体。自己的细线 SVG 图标、平直选项边框、少量粉色刻线；不复制明日方舟美术资产或标识。

STORY: 四条角色路线与独立终章，十二个结局。阅读中能立即找到回看、隐藏界面、自动、已读跳过和暂停菜单。不会把被跟踪与被控制统一收束成幸福恋爱。

FIRST VIEWPORT: 标题态左侧大书名与敲门对白，右侧悬浮游戏菜单。阅读态全屏舞台，左上菜单/设置/回看/隐藏，右上自动/已读跳过，下方低对比章节和时间，底部宽渐变对白区，不使用网页侧栏或圆角对话卡片。选择居中横向展开，五个选项仍可阅读。手机竖屏上下排列对白；横屏高度不足时选项组独立滚动，避免压住对白。

FORM: 用户所附两张明日方舟截图是阅读结构参考，明确要求参考而不照抄，不是逐像素复刻图。提取全屏场景、轻 HUD、底部对白与中央选项的关系。媒体清单登记 16 张背景、17 套透明衣装立绘和 12 张 CG；画风承接已认可的 v3 纯日系二维角色，原风格参考只用于画法，不复制人物设计。逐句 cue 决定背景、衣装、照片与 CG 出现时机；CG 不叠加重复人物，手机照片与远程对白保持叙事位置。人物衣装和场景回忆复用暗色弹窗、原有字体、平直容器与粉色操作反馈；回忆按既有已读记录解锁。沿用已核验的流程引用 seed:edf4085cd059637f，原配色、字体层级与阅读版式保持；不为媒体接入重抽方向。H 隐藏界面、L 回看、Esc 暂停；减少动态效果时关闭雨幕。

FINISH: 媒体清单与每张 PNG 的同名 .png.json 保留生成来源，DESIGN.md / sidecar 同步实际已有的衣装与回忆界面。桌面、手机、横屏的媒体显示、对白可读性与交互验证记录在 docs/VERIFICATION.md；文档同步不构成新的测试通过结论。
