# 你明明醒着

以用户提供的聊天导出中的居酒屋故事为素材改编的日系恋爱悬疑视觉小说。人物均为虚构成年人，实际聊天发送人已匿名化。

## 启动

安装 Node.js 22 或更新版本，在项目目录执行：

```powershell
npm start
```

打开 http://127.0.0.1:3000 。无需 npm install；游戏没有第三方运行时依赖。也可以双击 `启动游戏.cmd`。更换端口：`$env:PORT=3001; npm start`。

- 共通篇、凛/七濑/栞/晚晴四条角色路线、独立终章，共十二个结局：三个好结局、三个中性结局、六个坏结局。
- 完整保留墙边霸凌、凌晨敲窗、猫眼对视、堵门、追逐及枕上信封的冲突链。支线扩写证词反转、关系操控与不可逆的失败。

- 打字显示、键盘操作、自动播放、仅跳过已读、对白回看。
- 场景自动存档、六个手动存档、快速存读档、JSON 导出导入。
- 已读场景跳转和隐藏剧透的结局收集。导入存档会重放分支历史验证有效性。

## 阅读操作

点击舞台或“继续”读下一句；文字显示中点击可显示全文。空格 / Enter / → 继续，数字 1–5 选择，A 自动，S 存读档，L 回看，H 隐藏/显示界面，Esc 游戏菜单或关闭窗口。键盘焦点位于按钮时，Enter 执行该按钮。

存档只在当前浏览器内保存；无痕模式、清除网站数据或更换浏览器可能影响保存，建议使用导出功能备份。同一版本内开启新故事保留场景检查点与结局收集。本轮扩写保留 1.1 分支结构和存档空间；已读标记包含实际文本摘要，改写后的段落会重新显示为未读，避免跳过新内容。1.0 的进度不被覆盖，可在存读档菜单导出旧版备份，不能直接套入 1.1 剧情。

## 故事编辑

`public/story.js` 是完整剧本与分支图。场景包括 `lines`、`choices`、`next`、`ending`。选项 `set` 写入 0/1 标记，条件去向按顺序匹配，最后一项为默认分支。对白可带 `variants: [{when, text}]`，根据已发生的选择替换本句；导出剧本会列出默认文本和条件文本。新增结局时同时登记 `endings`。

各场景的 `outfits` 登记工作、日常、面试、凌晨来访等服装；`story.wardrobes` 是衣装表。`public/media.json` 用 `portraits.rin.work`、`portraits.rin['night-visit']` 等映射实际立绘。`public/visuals.js` 读取 `media.scenes`：`from` / `to` 是从 0 开始、包含两端的对白索引，可在同一节点内切换背景、CG、衣装，或隐藏立绘。远程说话人不会被画成站在主角房间里；特定手机照片以照片形式展示对应衣装。

场景回忆直接从已有已读记录推导，读到相应 CG 片段即可解锁；未读画面隐藏。此次图像接入沿用 1.1 存档，不另建存档版本。

```powershell
npm run story:check
npm run story:export
npm test
```

`docs/TRANSITIONS.md` 保存全部黑屏过渡台词；`public/transitions.js` 的 `节点:对白索引` 配置对应入场前的过渡。`docs/STORY.md` 是完整可审阅故事；`docs/walkthrough.json` 是每个结局的一条实际可行路线，含剧透。测试检查所有节点可达、结局可达、前置选择影响、存档恢复与文件隔离。

## 音乐与图像

配乐来自本项目的原创 MIDI 音高谱与本地加法合成，无现成商业音乐或人声采样。`scripts/synth-music.js` 可重新生成 `public/audio/*.wav`，具体谱面和参数保存在 `public/audio/credits.json`。

```powershell
npm run music:generate
```

用户认可 v3 日系二维面部方向后，本轮使用内置图像工具制作实际游戏素材。`public/media.json` 登记 16 张背景、17 套透明衣装立绘、12 张剧情 CG，共 45 张 PNG，位于 `public/art/production/{backgrounds,portraits,cgs}`；每张附同名 `.png.json`，记录完整提示词、参考用途、时间与实际工具。角色通过眼型、眉形、脸型和表情作适度区分，衣装随工作、日常及特定事件变化。

`public/art/character-sheets` 保留设计基准；设定板不直接裁成游戏立绘。本地 Anima 与偏半写实的未采纳研究保留作对照，运行时采用 production 清单。图像制作与接入说明见 `docs/ART.md`，本轮验证记录见 `docs/VERIFICATION.md`。本地模型和 Python 环境不属于游戏运行依赖。

## 素材与改编边界

原文件：`Assets/qq-20261023-181522-0d4165.json`。递归遍历合并转发后提取到 168 条指定叙述者的消息，见 `npm run source:inspect`，该命令输出匿名标识。保留的关键设定：双份打工、艺术大学院面试、三名女同事、牛丼店、长消息、墙边霸凌、凌晨四点敲窗、猫眼对视、追逐、枕上信封及辞职。

人物姓名、年龄、恋爱关系发展、心理动机、全部游戏对白与多结局均为新创作；不是对原聊天中的现实人物或任何地域、性别群体的事实判断。内容涉及跟踪、职场暴力、胁迫、关系破裂、伤害与死亡，亲密情节含蓄呈现。玩家从许砚的夜班现场开始，按时间顺序亲历事件；“夜航”仅是故事内朋友的化名，其他群友使用泛称。原始素材保留在本地，不应随公开发布的游戏分发。
