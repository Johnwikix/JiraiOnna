# 你明明醒着

> 起きてるんでしょう。——「开门吧。我想见你。先让我进去，好不好？」

一部日系恋爱悬疑视觉小说。十月，东京，雨。居酒屋打烊后的末班电车、凌晨四点的敲窗声、一条始终没回的消息——你的每个选择，决定这条夜晚的岔路通向哪一个结局。

[![Deploy](https://github.com/Johnwikix/JiraiOnna/actions/workflows/deploy.yml/badge.svg)](https://github.com/Johnwikix/JiraiOnna/actions/workflows/deploy.yml)

**[▶ 在线游玩](https://johnwikix.github.io/JiraiOnna/)** · 离线可玩，存档保存在浏览器本地。

以用户提供的聊天导出中的居酒屋故事为素材改编。人物均为虚构成年人，实际聊天发送人已匿名化。

> **内容提示**：故事涉及跟踪、职场暴力、胁迫、关系破裂、伤害与死亡，亲密情节含蓄呈现，面向成年玩家。

## 快速开始

**在线**：直接打开 [johnwikix.github.io/JiraiOnna](https://johnwikix.github.io/JiraiOnna/)，无需安装任何东西。

**本地**：安装 Node.js 22 或更新版本，在项目目录执行：

```powershell
npm start
```

打开 http://127.0.0.1:3000 。无需 `npm install`——游戏没有第三方运行时依赖。也可以双击 `启动游戏.cmd`。更换端口：`$env:PORT=3001; npm start`。

## 游戏内容

- **58 个场景、682 段对白**，全部正文约 25,573 字，22 个选择点，29 段条件替换（前置选择会改变后文的实际措辞）。
- **四条角色路线**：共通篇之后进入凛 / 七濑 / 栞 / 晚晴的独立路线，终章独立收束，共 **十二个结局**（三个好结局、三个中性结局、六个坏结局）。
- 完整保留墙边霸凌、凌晨敲窗、猫眼对视、堵门、追逐及枕上信封的冲突链。支线扩写证词反转、关系操控与不可逆的失败。
- 以主角许砚的动作、感官与当时判断推进；在冲突之间保留工作、交通、等待和消息往返的生活停顿。
- **16 张背景、17 套透明衣装立绘、12 张剧情 CG**；按对白进度切换画面与服装，CG 中隐藏重复立绘，远程说话人不会被画进主角的房间。
- **八首原创循环配乐**，按场景与角色切换，1.2 秒交叉淡化，可调整音量或关闭。配乐由本项目原创 MIDI 音高谱与本地加法合成生成，无商业采样。
- 自带开源中文标题字体子集，离线加载，许可和重建说明见 `docs/FONTS.md`。

## 游玩系统

- 打字机显示、自动播放、仅跳过已读、对白回看（回看呈现与当前分支一致的版本）。
- 场景自动存档、六个手动存档、快速存读档、JSON 导出导入；导入存档会重放分支历史验证有效性。
- 已读场景跳转和隐藏剧透的结局收集；五位角色的衣装浏览、随阅读进度解锁的场景回忆与完整原图查看。
- 场景与时间跳跃使用淡出 / 黑屏 / 淡入转场，65 段第一人称过渡台词衔接心理活动。带字转场始终等待玩家确认，自动阅读、已读跳过和切到后台都不会自动关闭；无字短黑屏自动过渡。
- 手机与桌面自适应布局、隐藏界面、全屏、系统减少动态效果、字号和显示速度设置。

### 阅读操作

| 操作 | 效果 |
| --- | --- |
| 点击舞台 / 继续 / 空格 / Enter / → | 读下一句；文字显示中点击可立即显示全文 |
| 数字 1–5 | 选择选项 |
| A | 自动播放开关 |
| S | 存读档 |
| L | 剧情回看 |
| H | 隐藏 / 显示界面 |
| Esc | 游戏菜单或关闭窗口 |

键盘焦点位于按钮时，Enter 执行该按钮。

### 存档说明

存档只在当前浏览器内保存；无痕模式、清除网站数据或更换浏览器可能影响保存，建议使用导出功能备份。同一版本内开启新故事保留场景检查点与结局收集。1.1 保留 1.0 的分支结构和存档空间；已读标记包含实际文本摘要，改写过的段落会重新显示为未读，避免跳过新内容。1.0 的进度不被覆盖，可在存读档菜单导出旧版备份，不能直接套入 1.1 剧情。

## 项目结构

```
public/            游戏本体（纯静态站点，无构建步骤）
  story.js         完整剧本与分支图
  engine.js        阅读引擎（状态、推进、选择、存档验证）
  app.js           界面与交互
  transitions.js   场景转场与过渡台词
  visuals.js       背景 / 立绘 / CG 的调度
  music.js         配乐播放器
  media.json       媒体清单（路径、衣装映射、场景线索）
  art/production/  背景与立绘成片（45 张 PNG 及生成记录）
  audio/           合成配乐与谱面 credits.json
  fonts/           标题字体子集
scripts/           剧本校验、导出、配乐合成、QA 与图像流水线
tests/             node:test 测试套件（63 项）
docs/              故事全文、转场台词、验证记录与说明文档
server.js          本地开发静态服务器
```

技术栈：原生 Node.js HTTP 服务 + 浏览器 ES Modules，**零运行时 npm 依赖**。`public/` 可直接被任何静态服务器托管。

## 剧本编辑

`public/story.js` 是完整剧本与分支图。场景包括 `lines`、`choices`、`next`、`ending`。选项 `set` 写入 0/1 标记，条件去向按顺序匹配，最后一项为默认分支。对白可带 `variants: [{when, text}]`，根据已发生的选择替换本句；导出剧本会列出默认文本和条件文本。新增结局时同时登记 `endings`。

各场景的 `outfits` 登记工作、日常、面试、凌晨来访等服装；`story.wardrobes` 是衣装表。`public/media.json` 用 `portraits.rin.work`、`portraits.rin['night-visit']` 等映射实际立绘。`public/visuals.js` 读取 `media.scenes`：`from` / `to` 是从 0 开始、包含两端的对白索引，可在同一节点内切换背景、CG、衣装，或隐藏立绘。场景回忆直接从已有已读记录推导，读到相应 CG 片段即可解锁。

`docs/TRANSITIONS.md` 保存全部黑屏过渡台词；`public/transitions.js` 的 `节点:对白索引` 配置对应入场前的过渡。`docs/STORY.md` 是完整可审阅故事；`docs/walkthrough.json` 是每个结局的一条实际可行路线，含剧透。

## 音乐与图像

配乐为原创 MIDI 音高谱经本地加法合成生成，无现成商业音乐或人声采样：

```powershell
npm run music:generate   # 重新生成 public/audio/*.wav，谱面与参数见 public/audio/credits.json
```

图像使用内置图像工具按日系二维方向批量制作：16 张背景、17 套透明衣装立绘、12 张剧情 CG，共 45 张 PNG，位于 `public/art/production/{backgrounds,portraits,cgs}`，每张附同名 `.png.json` 记录完整提示词、参考用途与实际工具。角色通过眼型、眉形、脸型和表情作适度区分。`public/art/character-sheets` 保留设计基准。图像制作与接入说明见 `docs/ART.md`，验证记录见 `docs/VERIFICATION.md`。本地模型和 Python 环境不属于游戏运行依赖。

## 测试与校验

```powershell
npm test                    # 63 项测试：节点/结局可达、前置选择影响、存档恢复、文件隔离、转场、媒体调度
npm run story:check         # 剧本结构校验
npm run story:export        # 导出可审阅剧本
node scripts/check-media.js # 媒体清单与素材文件一致性校验
```

`scripts/qa-*.js` 为浏览器端叙事、转场、图像与路线矩阵的 QA 脚本。

## 部署

推送到 `main` 即通过 [GitHub Actions](.github/workflows/deploy.yml) 自动发布 `public/` 到 GitHub Pages。站点挂在 `/JiraiOnna/` 子路径下，因此 `public/` 内所有资源引用使用相对路径（`app.js` 加载 `media.json` 时会把其中的根绝对路径归一化为相对路径）；新增资源时请保持这一约定。
